# Адаптивные макеты для мобильного приложения ЖК River Park

## Поддерживаемые устройства

### 📱 Смартфоны
- **iPhone SE (2022)**: 375x667px (4.7")
- **iPhone 13/14/15**: 390x844px (6.1")
- **iPhone 15 Plus**: 428x926px (6.7")
- **Android Compact**: 360x640px (5.0")
- **Android Standard**: 412x892px (6.2")
- **Android Large**: 428x926px (6.8")

### 📱 Планшеты (опционально для будущих версий)
- **iPad Mini**: 768x1024px (8.3")
- **iPad**: 820x1180px (10.9")
- **Android Tablet**: 800x1280px (10.1")

---

## Система адаптивных контрольных точек

### Breakpoints:
```css
/* Extra Small - компактные телефоны */
@media (max-width: 375px) {
  /* iPhone SE, малые Android */
}

/* Small - стандартные телефоны */
@media (min-width: 376px) and (max-width: 414px) {
  /* iPhone 13/14, большинство Android */
}

/* Medium - крупные телефоны */
@media (min-width: 415px) and (max-width: 767px) {
  /* iPhone Plus, крупные Android */
}

/* Large - планшеты */
@media (min-width: 768px) {
  /* iPad Mini и больше */
}
```

### Минимальные размеры:

## Accessibility (Доступность)

### Поддержка масштабирования:
- **100%**: стандартные размеры
- **125%**: увеличение на 25%
- **150%**: увеличение на 50%
- **200%**: максимальное увеличение

### VoiceOver/TalkBack поддержка:
- Семантическая разметка
- Описательные labels
- Логичный порядок навигации
- Озвучивание состояний

### Цветовая доступность:
- Контрастность 4.5:1 для обычного текста
- Контрастность 3:1 для крупного текста
- Поддержка высококонтрастных тем
- Альтернативы цветовому кодированию

Эта система адаптивности обеспечивает:
✅ Оптимальное отображение на всех устройствах
✅ Удобство использования для всех возрастных групп
✅ Соответствие рекомендациям Apple HIG и Material Design
✅ Поддержку функций доступности
✅ Масштабируемость для будущих устройств
