# Wireframes и прототипы интерфейсов ЖК River Park

## Корпоративный стиль на основе сайта riverpark62.ru

### Цветовая палитра:
- **Основной зеленый**: #2d5a3d (из логотипа и брендинга)
- **Акцентный зеленый**: #4a7c59
- **Светло-зеленый**: #e8f5e8
- **Серый основной**: #333333
- **Серый светлый**: #f8f9fa
- **Белый**: #ffffff
- **Красный (ошибки)**: #dc3545
- **Желтый (предупреждения)**: #ffc107
- **Синий (информация)**: #0066cc

### Типографика:
- **Заголовки**: Montserrat, sans-serif (жирный)
- **Основной текст**: Inter, sans-serif (обычный)
- **Кнопки**: Inter, sans-serif (полужирный)

### Принципы дизайна:
- Минимализм и чистота (в стиле сайта)
- Гармония с природой (природные оттенки)
- Удобство для всех возрастов
- Крупные элементы интерфейса
- Интуитивные иконки

## 🎨 Дизайн-система

### Компоненты:

#### Кнопки:
- **Основная** (зеленая): #2d5a3d, белый текст, скругленные углы 8px
- **Вторичная** (контур): прозрачная, зеленая рамка, зеленый текст
- **Опасная** (красная): #dc3545, белый текст

#### Карточки:
- Белый фон, тень: 0 2px 8px rgba(0,0,0,0.1)
- Скругленные углы: 12px
- Отступы: 16px

#### Поля ввода:
- Рамка: 1px solid #ddd
- Фокус: зеленая рамка #2d5a3d
- Скругленные углы: 8px
- Высота: 48px (для удобства пожилых пользователей)

#### Иконки:
- Размер: 24px (обычные), 32px (крупные действия)
- Стиль: outline, заполненные для активных состояний
- Цвета: #666 (неактивные), #2d5a3d (активные)

### Адаптивность:
- Минимальная область касания: 44px
- Крупный текст: 16px+ для основного содержимого
- Контрастность: минимум 4.5:1
- Поддержка VoiceOver/TalkBack

### Анимации:
- Переходы между экранами: slide (300ms)
- Кнопки: scale + opacity (150ms)
- Загрузка: spinner + skeleton screens
- Микро-анимации для обратной связи
